# 結婚式見積もり「闇」チェッカー ＆ 節約シミュレーター

プレ花嫁向けの結婚式費用シミュレーターです。  
初期見積もりから最終費用の差額を可視化し、実質的な自己負担額をリアルタイムで計算します。

## 機能

- 📊 **闇チェック**: 見積もりが爆上がりする典型的な追加費用を可視化
- 💰 **節約シミュレーター**: 持ち込み・外注による節約額をシミュレーション  
- 💍 **結婚指輪**: ブランド別の費用を加算した総額計算
- 🎉 **実質負担額**: ご祝儀・会費を差し引いた自己負担額をリアルタイム表示

## デプロイ

このサイトは [Vercel](https://vercel.com) 上でホスティングされています。  
`main` ブランチへのプッシュで自動デプロイされます。

## 技術スタック

- HTML5 + Vanilla JavaScript
- Tailwind CSS (CDN)
- Google Fonts
